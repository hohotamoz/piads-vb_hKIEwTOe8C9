الخطوة 2: إنشاء مشروع Supabase
Supabase هو قاعدة البيانات والمصادقة للتطبيق
⚠️ هذه الخطوة مطلوبة لعمل التطبيق

بدون Supabase، لن تعمل قاعدة البيانات أو تسجيل الدخول. الخدمة مجانية للمشاريع الصغيرة.

1. إنشاء حساب وملف مشروع

  1. اذهب إلى supabase.com وسجل حساباً مجانياً
  2. اضغط "New Project"
  3. اختر اسماً للمشروع (مثلاً: piads)
  4. أنشئ كلمة مرور قاعدة البيانات واحتفظ بها
  5. اختر المنطقة الأقرب لك (المملكة العربية السعودية: eu-central-1)
  6. اضغط "Create new project" وانتظر 2 دقيقة
🚀 إنشاء مشروع Supabase

2. الحصول على مفاتيح API

بعد إنشاء المشروع، اذهب إلى:

Project Dashboard → Settings → API

ستجد ثلاثة أشياء مهمة:

  • 🔗 Project URL — يبدأ بـ https://xxxxx.supabase.co
  • 🔑 anon/public key — مفتاح JWT طويل يبدأ بـ eyJ
  • 🔐 service_role key — مفتاح سري (لا تشاركه أبداً!)
⚠️
لا تضع service_role key في كود frontend أو GitHub. فقط في .env.local وفي Vercel environment variables.
🏗️
الخطوة 3: إعداد قاعدة البيانات
تشغيل SQL لإنشاء الجداول والسياسات
ℹ️
الملف scripts/setup-database.sql في المشروع يحتوي على كل شيء. تم تحديثه ليشمل جميع الجداول الناقصة.

كيفية تشغيل SQL

  1. اذهب إلى Supabase Dashboard → SQL Editor
  2. اضغط "New query"
  3. افتح ملف scripts/setup-database.sql من المشروع
  4. انسخ المحتوى كاملاً والصقه في SQL Editor
  5. اضغط "Run" (أو Ctrl+Enter)
-- Enable UUID extension
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- 1. profiles جدول
CREATE TABLE IF NOT EXISTS public.profiles (
  id uuid PRIMARY KEY references auth.users(id),
  email text UNIQUE NOT NULL,
  name text, role text DEFAULT 'user',
  avatar text, verified boolean DEFAULT false,
  ...
);

-- 2. ads جدول + 3. messages + 4. notifications + 5. reviews
-- 6. Storage bucket + 7. RLS Policies
-- راجع scripts/setup-database.sql في المشروع
✅
إذا ظهرت رسالة "Success" بعد Run، فالجداول جاهزة! إذا ظهر خطأ يقول "already exists"، فالجداول موجودة بالفعل — لا مشكلة.

الخطوة 4: إعداد متغيرات البيئة
أنشئ ملف .env.local في مجلد المشروع
⚠️
الملف .env.local لا يُرفع على GitHub تلقائياً (موجود في .gitignore). لا تشاركه مع أحد.

🛠️ مولّد ملف .env.local التفاعلي

أدخل قيمك وسيتم توليد الملف تلقائياً:

🔐 Supabase Service Role Key *

🔵 Google Client ID (اختياري)
🔵 Google Client Secret (اختياري)
📘 Facebook App ID (اختياري)
🌐 App URL (للإنتاج فقط)

الخطوة 5: تشغيل التطبيق
تشغيل محلي للتطوير والاختبار
# تشغيل خادم التطوير
npm run dev
✅
سيعمل التطبيق على http://localhost:3000 — افتحه في المتصفح.
# بناء للإنتاج
npm run build

# تشغيل إصدار الإنتاج
npm start
⚠️
استخدم npm run build فقط قبل النشر. يأخذ 2-3 دقائق.

✅ قائمة التحقق بعد التشغيل

حل مشاكل شائعة

❌
خطأ: "Cannot find module"
الحل: rm -rf node_modules && npm install
❌
خطأ: "Supabase credentials not found"
الحل: تأكد من وجود ملف .env.local وأنك أعدت تشغيل الخادم بعد إنشائه.
❌
White screen / شاشة بيضاء
الحل: افتح Console في المتصفح (F12) وشارك الخطأ الظاهر.

الخطوة 6: إعداد OAuth
تسجيل الدخول بجوجل وفيسبوك (اختياري)

1. إنشاء Google OAuth Credentials

  1. اذهب إلى console.cloud.google.com
  2. أنشئ مشروعاً جديداً أو اختر موجوداً
  3. APIs & Services → Credentials → Create Credentials → OAuth client ID
  4. Application type: Web application
  5. أضف Authorized redirect URI:
    https://YOUR_SUPABASE_PROJECT.supabase.co/auth/v1/callback
  6. احتفظ بـ Client ID و Client Secret
فتح Google Console

1. إنشاء Facebook App

  1. اذهب إلى developers.facebook.com
  2. Create App → Consumer → أدخل اسم التطبيق
  3. من Dashboard → Add Product → Facebook Login → Web
  4. Settings → Basic → احتفظ بـ App ID و App Secret
  5. Facebook Login → Settings → Valid OAuth Redirect URIs:
    https://YOUR_SUPABASE_PROJECT.supabase.co/auth/v1/callback
فتح Facebook Developers

2. تفعيل OAuth في Supabase

  1. Supabase Dashboard → Authentication → Providers
  2. ابحث عن Google وفعّله
  3. أدخل Client ID و Client Secret من Google Console
  4. كرر لـ Facebook
  5. احفظ التغييرات
✅
بعد الإعداد، زر "تسجيل الدخول بجوجل/فيسبوك" سيعمل تلقائياً في التطبيق.

الخطوة 7: النشر على Vercel
نشر مجاني وسريع مع دعم تلقائي لـ Next.js
✅
Vercel هو الاختيار الأمثل لـ Next.js — نشر مجاني، SSL تلقائي، وأداء ممتاز عالمياً.

الطريقة الأسرع (عبر GitHub)

  1. ارفع المشروع على GitHub (مستودع خاص أو عام)
  2. اذهب إلى vercel.com وسجل بحساب GitHub
  3. اضغط "Import Project" واختر مستودعك
  4. في خطوة "Configure Project"، اضغط "Environment Variables"
  5. أضف جميع متغيرات .env.local واحداً واحداً
  6. اضغط "Deploy" وانتظر 2 دقيقة
# رفع على GitHub
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main

بعد النشر: تحديث Redirect URLs

⚠️
في Supabase Dashboard → Authentication → URL Configuration، أضف:
Site URL: https://your-app.vercel.app
Redirect URLs: https://your-app.vercel.app/auth/callback
